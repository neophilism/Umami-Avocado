# Umami Avocado

An extensible AI-directed scientific research platform. The first research program concerns umami chemistry in food yeast; later modules include avocado and other organisms.

**Status:** repository initialized. The application, laboratory integrations, scientific experiments, and production deployment are not implemented by this commit.

The foundational implementation is tracked as **UA-001**, with the remaining work described in a 30-unit development roadmap. No cloud-laboratory orders or charges are permitted by default.
